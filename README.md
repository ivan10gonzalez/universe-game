# Universe Game — Casino Demo

Demo de frontend para pruebas, inspirada en la estética espacial de Universe Game.

Incluye:
- Menú lateral con las tres rayas.
- Inicio, Casino, Juegos y Perfil.
- Jewel Rush, Cosmic Slots y Galaxy Roulette.
- Navegación directa a cada juego.
- Fichas virtuales locales para pruebas.
- API `/api/health`.
- Configuración para Render.

## Ejecutar localmente

```bash
npm install
npm start
```

Abrir http://localhost:3000

## Deploy

Se puede publicar en Render con:
- Build: `npm install`
- Start: `npm start`
- Health Check: `/api/health`

Este proyecto es solo una demo de fichas virtuales; no maneja dinero real, depósitos ni retiros.
